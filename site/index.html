Why Thawr

A private network you own end to end.

No vendor control plane, no identity provider you must sign up for, no fleet of containers to keep alive. One process runs the network and it keeps running when the internet does not.

One process, one line of config

A server starts with public_addr and nothing else. SQLite is embedded, so the whole server state is one directory.

WireGuard, as it is

The kernel module where present, wireguard-go otherwise. Thawr never implements cryptography of its own.

Direct first, relay when it must

Peers find each other with STUN and hole punching. When two strict NATs get in the way, the relay built into the server carries packets it cannot read.

Default deny

Write who may reach what in a YAML file you keep in git. A peer without a rule cannot see another, and the receiving peer filters ports as well.

Phones join with a QR code

Scan it in the official WireGuard app. The server keeps only the public key, and the phone resolves peer names through the hub.

Subnet routers and exit nodes

A Linux peer advertises the network behind it, or itself as an exit node. An admin approves, and the policy says who may use it.

Keys that cannot change quietly

Every device pins the hub's key and the keys of the peers it reaches. A changed key stays out of the tunnel until you run thawr client trust. The optional network lock adds signatures the server never sees.

Nothing phones home

It starts and runs with no internet access. Names like nas.thawr resolve from the netmap the client already has.

How it works

From a bare server to a working network in four steps.

  1. Start the server

    On a host with a public address. This writes the config, registers the service and starts it at boot.

    sudo thawr server install --public-addr vpn.example.com

  2. Create a user and a one-time token

    The token enrols one device and then stops working.

    thawr admin user create markus --role admin
thawr admin token create --owner markus --kind human

  3. Enrol each device

    On every machine except the server. Phones use a QR code from thawr admin peer add-mobile.

    sudo thawr client install --server https://vpn.example.com \
  --token thawr_... --fingerprint sha256:...

  4. Check the paths, then use the names

    One table shows whether the control connection, a path to a peer or the policy is the problem.

    thawr client status
ssh nas.thawr

What you can rely on

Small surface, stated limits.

No homemade cryptography

WireGuard carries the tunnel. Hashing, password storage and randomness come from Go's standard and x/crypto packages.

Reproducible builds

CI builds every target twice and fails unless the archives are byte-identical. Each release ships with SHA256SUMS.

A published threat model

Phone traffic goes through the hub, so the server can read it, unlike the end-to-end tunnels between laptops and servers. Read the threat model.

غار ثور

Thawr is named after the cave near Mecca where the Prophet Muhammad ﷺ and Abu Bakr found shelter during the Hijra: hidden, protected, reachable only by those who belong. The mark is a cave arch built from a mesh of nodes, sheltering a smaller mesh.
